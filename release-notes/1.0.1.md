Fixes from the community directory review.

- The bundle no longer contains code that creates `<script>` elements. These were unused Internet Explorer polyfills inside the ExcelJS browser build, and the build now fails if they ever come back.
- Minimum Obsidian version is now 1.7.2.
- Async actions report errors instead of failing silently, and values are always shown as readable text.
- Styles no longer use `!important`, so themes and CSS snippets can override them.
- Updated the `uuid` dependency to a version without known advisories.
