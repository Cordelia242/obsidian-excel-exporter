First public release.

- Template manager: one card per Excel template, with a preview of the workbook.
- Visual editor in four steps: which notes are exported (with suggestions from your vault and a visual filter builder), related notes (auto-detected backlinks and subsets), cell mapping (pick the source, the field and how to show it; repeat rows per related note), and output options.
- Export dialog with a searchable list of notes, and a preview inside Obsidian before writing the `.xlsx` files.
- Keeps the template formatting: styles, column widths, merged cells and formulas (adjusted when rows are repeated).
